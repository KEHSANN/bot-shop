## Shared Rules
1. Service implementations MUST reside in their domain-owned `app/services/*_service.py` files rather than a shared monolithic `crud.py`.
2. Read-only imports across boundaries (e.g., `web-admin` calling `ShopService`, `PaymentService`, `UserService`, `CMSService`, `AnalyticsService`) MUST follow `app/services/interfaces.py` and `app/services/dtos.py`.
3. Any contract change to `dtos.py`, `interfaces.py`, or `models.py` during Wave 2 MUST be requested on the board and executed by `db-architect` (or coordinator-designated owner) with an Alembic migration if schema changes.
